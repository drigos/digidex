Guilmon: evolution tree

Fresh -> In-Training -> Rookie -> Champion -> Ultimate -> Mega hierarchy, with the X-Antibody line, the Data (Yellow) variants, the Virus / dark line, the Digital Hazard (Megidramon) branch and the Gallantmon mode changes.
Digivolution triggers
Names link to DigimonWiki/Fandom (Fandom community, CC BY-SA unless noted otherwise); artwork © Bandai, via the official Reference Book and Wikimon. Card labels show Level (+ Virus / X); edge colors show the digivolution trigger. Bio-Merge (Matrix Evolution) to Gallantmon is drawn as a Normal evolution. Grani is an external support unit / steed, not an evolution stage. One theory holds that Megidramon and ChaosGallantmon are the same being seen as either a dark dragon or a dark knight; this is drawn as a lore link, not a path.
